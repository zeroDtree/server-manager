# 使用 GSAD

## 简介 {#gsad}

**GSAD**（GPU Server Access Dashboard）用于申请 GPU 服务器的 SSH 访问，并管理其上的 Linux 账号。申请访问会在目标主机创建 Linux 账号，**不会**独占预留 GPU。

## 登录 {#gsad_login}

1. 打开 GSAD 登录页。使用管理员提供的邮箱和初始密码。
2. 账号由管理员导入开通。首次登录后建议 [修改密码](#gsad_change_password)。如需开通请联系管理员。

右上角 **语言** 可在 中文 / English 之间切换。选择会保存在浏览器中。

![GSAD 登录页](../assets/zh/login.png)

## 查看资源看板 {#gsad_board}

登录后，侧栏 **资源看板** 打开 **GPU 资源负载**。数据大约每 45 秒自动刷新。每页最多 20 个节点。

用 **全部等级** 和 **全部状态**（在线 / 离线 / 维护）筛选。**刷新** 可立即重载。节点较久未上报时会出现 **数据可能过期** 标记。

每行显示状态、服务器 ID、资源等级、GPU 数、平均利用率、平均显存，以及采集 / 上报时间。行下方的 GPU 表列出型号、利用率、显存、显存占用，以及采集时间（Agent）/ 最近上报（服务端）。点标题栏 **立即申请**，或行内 **申请此服务器**，会带着该主机进入新建申请。

![资源看板](../assets/zh/board.png)

## 申请 GPU 服务器访问 {#gsad_apply}

申请访问会在目标服务器创建 Linux 账号。Linux 用户名来自你的 GSAD 资料（由管理员导入）。SSH 密码可选；留空时，授权完成后系统会生成初始密码。

### 新建申请

在侧栏选择 **新建申请**。可选填写 **SSH 登录密码（可选）**（填写时须 8–128 位）。留空则在授权完成后自动生成初始密码。然后点 **提交申请**。

![新建申请](../assets/zh/apply.png)

### 选择目标服务器

**目标服务器** 下拉中，每项格式为 `server_id · 资源等级 · 状态`（例如 `gpu-mock-003 · L40S · 在线`）。选中节点后点 **提交申请**。也可以从看板进入，此时主机会已预选。

![选择目标服务器](../assets/zh/apply-target.png)

### 查看我的申请

侧栏 **我的申请** 列出你的记录。列表大约每 60 秒自动刷新。可用 **全部状态** 筛选，或点 **刷新**。新提交的行会短暂高亮。

点任意一行打开详情。常见状态：

| 状态 | 含义 |
| --- | --- |
| 授权处理中 | 后端正在创建 Linux 账号。可 **取消申请** 以停止开通；此时服务器上尚未创建账号。 |
| 已生效 | 可查看连接信息（IP、用户名、初始密码）。 |
| 回收中 / 已撤销 | 访问已撤销；账号及其数据已删除。 |
| 授权失败 / 回收失败 | 服务器未能完成操作。请稍后重试或联系管理员。 |
| 已取消 | 在账号创建前取消了申请。 |

![我的申请](../assets/zh/applications.png)

状态为 **授权处理中** 时，详情提供 **取消申请**。这只会停止开通流程。

![授权处理中可取消](../assets/zh/application-authorizing.png)

### 查看连接信息

状态为 **已生效** 时，点该行打开 **申请详情**。**连接信息** 显示服务器 IP、用户名和初始密码。每项都有复制按钮；密码默认遮盖，可点显示。请妥善保管初始密码，首次登录后尽快修改。

| 字段 | 说明 |
| --- | --- |
| 服务器 IP | NetBird 虚拟 IP，用于 `ssh` 登录 |
| 用户名 | Linux 登录账号名（来自 GSAD 资料） |
| 初始密码 | 首次登录使用；请妥善保管 |

![申请详情](../assets/zh/application-detail.png)

## 撤销访问 {#gsad_revoke}

> [!WARNING]
> 撤销访问会删除该服务器上你的 Linux 账号及其全部数据，且不可恢复。

1. 打开 **我的申请**，点该行打开 **申请详情**。
2. 点 **撤销访问**，并在对话框中确认。

同一详情里可以看到警告和 **撤销访问** 按钮（见上文 [连接信息](#gsad_apply)）。

撤销后状态变为 **回收中**，完成后变为 **已撤销**。

![回收中](../assets/zh/application-revoking.png)

![已撤销](../assets/zh/application-revoked.png)

状态为 **授权处理中** 时，请改用 **取消申请**。

## 修改密码 {#gsad_change_password}

在侧栏底部点 **修改密码**。输入 **当前密码**、**新密码**、**确认新密码**，然后 **保存**。新密码须 8–128 位，且不能与当前密码相同。修改成功后回到资源看板。

这里只更新 GSAD 控制台登录密码，不会改服务器 SSH 密码。

![修改登录密码](../assets/zh/change-password.png)

## 退出登录

在侧栏底部点 **退出登录**。随后回到登录页。
